# Rudransh Mathur — Portfolio

A one-page AI/ML portfolio built with Next.js and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

The project can be deployed directly to Vercel after pushing it to GitHub.

## Before publishing

1. Replace project-card GitHub links in `app/page.tsx` with the exact repository URLs.
2. Add your final PDF resume if you want a Resume button.
3. Verify all dates and project metrics.
4. Optionally add a profile photo to `public/` and place it in the About section.

The portfolio content is based on the supplied Rudransh Mathur resume.
